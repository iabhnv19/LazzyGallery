# Contributing to Lazzy Gallery

Thank you for your interest in contributing to Lazzy Gallery! We appreciate community contributions to make this media gallery even better.

## How Can I Contribute?

### Reporting Bugs
If you encounter a bug, please open an issue on GitHub and include:
- A clear, descriptive title.
- Steps to reproduce the behavior.
- Android device model, Android version, and app version.
- Logcat output or crash stack traces if applicable.

### Suggesting Enhancements
If you have a feature request or architectural improvement:
- Open a feature request issue.
- Explain clearly why the feature would be useful and how it aligns with our local-first, privacy-focused philosophy.

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure your code follows the existing Kotlin and Jetpack Compose coding style.
3. Test your changes thoroughly on an emulator or physical device.
4. Open a Pull Request with a clear description of the changes.
