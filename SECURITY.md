# Security Policy

## Supported Versions

Lazzy Gallery is an open-source, offline-first local media manager. Security updates are applied to the latest release.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Because Lazzy Gallery operates 100% locally with zero cloud backend or network telemetry, security concerns primarily relate to storage permissions, media file handling, or content provider interactions.

If you discover a security vulnerability, please report it directly via GitHub security advisories or by opening a private security issue. Please do not disclose security-sensitive issues publicly until a fix has been released.
